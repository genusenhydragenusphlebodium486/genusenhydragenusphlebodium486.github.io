## 🛠️ How to use the software

The application interface consists of three main tabs designed for straightforward management.

### Backing Up Mods
Choose the Backup tab to secure your files. The software scans your computer for installed Windhawk mods. You can select individual mods or back up your entire collection. Click the Start Backup button to save everything to a secure folder on your drive. The app shows a progress bar while it copies your binary files and registry keys.

The Restore tab allows you to return your Windhawk environment to a previous state. Choose a backup date from the list provided. Click the Restore button to overwrite your current settings with the saved data. The application restarts the necessary services to ensure your mods work as expected after the process finishes.

## 💡 Frequent Questions

Do I need to keep the program open?
No. You only need to run the program when you want to create a new backup or perform a restore. It does not run in the background.

Where does the application store my files?
It stores data in the folder you specify inside the Settings menu. If you do not change it, it uses a default folder in your Documents directory.

Can I move the backup folder to a cloud service?
Yes. You can point the backup location to a folder inside OneDrive, Google Drive, or Dropbox. This ensures your backups stay safe even if your computer hardware fails.

What happens if a backup fails?
The application shows an error message identifyng the cause. Most failures happen because of missing read permissions. Ensure you run the application with administrator rights if you back up registry keys.

Does this interfere with original Windhawk files?
No. The software copies the files to a separate location. It only touches your original files when you choose the restore option.

## 🛡️ Privacy and Security

The manager operates entirely offline. It does not send your mod data or registry configurations to any remote servers. Your files stay on your local machine or your preferred cloud storage provider. The application only connects to the internet to check for software updates from the GitHub repository.
